# 🏠 HomeSync AI

### AI-Powered Residential Maintenance Management Platform

HomeSync AI is a full-stack residential maintenance management platform designed to simplify and automate maintenance operations in apartment communities.

The platform combines **AI-powered complaint understanding**, **smart worker assignment**, **conflict-free scheduling**, **role-based access**, **real-time notifications**, and **analytics** into a single system.

---

## 🚀 Key Features

### 👤 Resident Management

- Secure resident registration and authentication
- Submit maintenance complaints using natural language
- Track maintenance requests
- View scheduled maintenance visits
- Receive notifications
- Rate completed maintenance services

### 🤖 AI Complaint Analysis

HomeSync AI analyzes natural-language maintenance complaints and automatically identifies:

- Maintenance category
- Subcategory
- Priority level
- Required worker skill
- Estimated repair duration
- Diagnostic explanation
- AI confidence score

#### Example

Input:

> "The bathroom tap has been leaking continuously since yesterday."

The AI can identify:

Category       : Plumbing
Subcategory    : Tap Leakage
Priority       : High
Required Skill : Plumbing
